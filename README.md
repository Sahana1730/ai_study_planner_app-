AI Study Planner

Overview

AI Study Planner is a simple smart scheduling application that helps students divide their syllabus efficiently before exams.

The user enters:

* Subject name
* Number of chapters
* Current date
* Exam date

The system automatically calculates:

* Total days remaining
* Chapters to study per day
* A clear daily study plan

This removes confusion about *how much to study each day* and helps students finish the syllabus on time.


Features

* Calculates remaining days until exam
* Automatically distributes chapters per day
* Generates an easy daily study target
* Prevents last‑minute syllabus rush


 Working Logic

1. User inputs subject and exam details
2. App finds number of days left
3. Divides chapters evenly across days
4. Displays daily study requirement

---

## 🎯 Purpose

To help students complete their syllabus consistently instead of cramming before exams.
